## Exact steps on your machine
1. Go to your existing studs clone and extract this bundle OVER it
   (your `.env` and `node_modules` are untouched — neither is in the bundle):
       tar -xzf studs-handover-2026-10-01.tar.gz -C /path/to/studs
2. Review before you commit:
       cd /path/to/studs && git status && git diff
3. Backend:
       npm install
       npm run build
       # run with your existing .env (PORT, JWT_SECRET, Paystack TEST keys, DB)
       node dist/main
4. Frontend:
       cd studs-frontend && npm install
       npm run dev        # or: npm run build && npx vite preview
5. Optional proof run (fake provider, fresh throwaway DB, no real money):
       python3 test/momo-regression.py     # expect: 69 passed, 0 failed
6. Commit + push when you're happy with the diff. Nothing has been
   committed for you.

## Final browser tour (2026-10-01, desktop viewport, seeded demo)
All four roles checked live (student, vendor, rider, admin) with real data.
Two defects found and fixed in this bundle, both re-verified live afterwards:
1. Wallet subscription card read "Renews Invalid Date · GHS NaN" — the
   frontend read `currentPeriodEnd`/`price`; the API returns
   `periodEnd`/`priceGHS`. Fixed in `studs-frontend/src/pages/Wallet.tsx`.
   Now reads e.g. "Renews 10/31/2026 · GHS 15.00".
2. Page headings overlapped their subtitles (subtitle struck through the
   heading letters) — `h1` had no line-height, so it inherited a 26px line
   box at 56px font size. Fixed with `line-height: 1.12` on `h1` (plus an
   `h3` guard) in `studs-frontend/src/index.css` and the PageShell title
   in `studs-frontend/src/components/ui.tsx`.
Phone-width was not checked on the assistant's side (the tour browser
cannot resize) — the phone pass above is yours; see "Test it on your phone".
